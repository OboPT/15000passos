# 15000passos

Registo diário de passos de 8 de novembro a 31 de dezembro de 2026, para fechar o ano com 15.000 passos de média diária.

- Abrir `index.html` (ou o site em GitHub Pages). Pode ser instalado no ecrã inicial (PWA).
- Os dados ficam no `localStorage` do dispositivo.
- "Mais → Exportar JSON" para cópia de segurança e "Importar JSON" para restaurar ou mudar de dispositivo.
